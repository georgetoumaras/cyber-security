Επισκόπηση Έργου

Αυτό το έργο (Τελική Εργασία για το μάθημα Ασφάλεια Συστημάτων Υπολογιστών) εστιάζει στη μελέτη, την υλοποίηση και τη συγκριτική αξιολόγηση τριών κρίσιμων πρωτοκόλλων ασφάλειας δικτύων: TLS, IPSec και Tor. Ο κύριος στόχος είναι η διασφάλιση των θεμελιωδών αρχών της ασφάλειας δικτύων: Εμπιστευτικότητα, Ακεραιότητα και Ανωνυμία.

🛠️ Τεχνολογίες και Υλοποίηση

Η υλοποίηση βασίστηκε στην Python και τη βιβλιοθήκη sockets.

Βασική Επικοινωνία (Μη Ασφαλής)

    Δημιουργήθηκε ένα βασικό μοντέλο επικοινωνίας Client-Server σε επίπεδο εφαρμογής (Layer 7) χρησιμοποιώντας TCP sockets.

    Αυτό το περιβάλλον χρησίμευσε ως βάση για την ενσωμάτωση των πρωτοκόλλων ασφαλείας.

Ενσωμάτωση Πρωτοκόλλων

    TLS (Transport Layer Security): Εφαρμόστηκε για κρυπτογράφηση και αυθεντικοποίηση (authentication) της σύνδεσης, διασφαλίζοντας την εμπιστευτικότητα και την ακεραιότητα των δεδομένων.

    IPSec Tunneling: Χρησιμοποιήθηκε για τη δημιουργία μιας προστατευμένης διόδου (tunnel), προσθέτοντας ασφάλεια στο Layer 3 (Επίπεδο Δικτύου).

    Tor (The Onion Router): Ενσωματώθηκε για την επίτευξη ανωνυμίας και ιδιωτικότητας στο επίπεδο των εφαρμογών.

   Βασικά Αποτελέσματα

Το έργο καταδεικνύει πώς ο συνδυασμός διαφορετικών μηχανισμών ασφάλειας μπορεί να παρέχει διπλή προστασία και να καλύπτει εξειδικευμένες απαιτήσεις ιδιωτικότητας και ασφάλειας σε διάφορα επίπεδα του μοντέλου δικτύωσης.
